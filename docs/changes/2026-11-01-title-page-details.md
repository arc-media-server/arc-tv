# Title pages: episode cards and the full description (1 November)

What changed, to match the Apple TV app's title pages more closely:

- **Episode cards** are a little wider (400px) and show, under the still, a small "EPISODE 3"
  line, the episode's name, three lines of its description (always, not only when focused) and
  its length, or the time left when it's part-watched.
- **Description:** beside the buttons it still shows three lines. When that cuts it short,
  "MORE" appears beneath and the description can be focused (Right from the last button); OK
  opens the whole text in a panel, and Back or OK closes it, returning to the description.
- Cast was already round photos with the character underneath, as Apple's.

Limits: whether the description is cut short is measured once when the page shows it, so a font
that loads late could leave MORE missing on a borderline description.

Logging: none added; these are layout changes with no new loads.
