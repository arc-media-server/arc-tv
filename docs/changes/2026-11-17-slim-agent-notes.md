# Slimmer agent notes

repository shares, now kept once in arc-media-server's `docs/AGENT-RULES.md` (owner, 17 November:
the notes are loaded into every turn of a session, so shorter notes cost less). `CLAUDE.md` now
imports `AGENTS.md` (`@AGENTS.md`), so Claude loads it without having to open it. No rule was
dropped.
